## Notational convention for modal operators (settled 2026-07-30)
**PRIMITIVE operators: `dia_x` (◇_x) and `box` (□).**
- `box` (□, unsubscripted) = promotes ALL variables through a box (standard necessity; `necIntro` over all boxed vars).
- `dia_x` (◇_x, subscripted) = object-witness diamond: promotes the variable `x` through a diamond (via `Pos`/realization-set), everything else through boxes. THE genuinely new operator.

**DERIVATIVE / notational variations:**
- `dia` (◇, unsubscripted) = `¬box¬` = de-dicto/propositional diamond (all vars boxed). (= `WFF.dia'` in code.)
- `box_x` (□_x, subscripted) = `¬dia_x¬` = restricted necessity ("necessarily, at the worlds where x is realized"; the Kripke free-logic reading — see `necessity_of_identity` in InterestingTheorems).

So: unsubscripted box/dia = "all variables boxed" (de-dicto); the `_x` subscript singles out `x` for diamond-promotion (de-re/object-witness). Keep `dia` (propositional ¬box¬) rigorously distinct from `dia_x` (object-witness) — they read similarly but differ; conflating them is an easy slip (flagged re: `dia_intro`).
