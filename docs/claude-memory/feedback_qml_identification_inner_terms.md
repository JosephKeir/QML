Any identification of possible terms must mean an identification of the inner terms at each world
where they exist. With different witnesses that is impossible unless something supplies a map
(e.g. a bijection) between the two inner contexts. `Here(s,t) ∧ Here(s,t')` should mean t and t'
are the same object at every type (the obvious reading), not merely indiscernible.

**Why:** every earlier witness-equality attempt broke this — §10.8 eqDia renamed one content
address into the other without any map (degenerate); §10.23/10.33 `Ind` identified without
identifying inner terms (disjoint extents allowed); §11.16's object-level ≈ composed links through
a middle object with no map. Each failed for that reason.

**How to apply:** check any design that relates possible objects across witnesses against this
principle first: where does the map between the inner contexts come from, and is the comparison
made at each shared world? The arrow atom `In` (docs/v12-modal-extensions.md §12) is the
candidate that meets it. Related: [[feedback_qml_joint_possibility_pairing]],
[[feedback_qml_unlinked_equality_model_law]] (the latter is superseded for `Here` if `In` is
adopted).
